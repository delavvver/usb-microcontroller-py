Данный блок повествует о методе передачи команд управления на микроконтроллер.
Для удобства и возможности расширения системы предлагается разработать пакет информации.
Примеры структуры пакета.

1.
  Заголовок - 1 байт;
  
  Команда - 1 байт;
  
  Полезная нагрузка - 5 байт;
  
  Окончание - 1 байт;

3.
  Заголовок - 1 байт;
  
  Длина - 1 байт;
  
  Данные - от 1 до 254 байт;
  
  Проверочный блок - 1 байт;

Первый тип удобен для команд так как заголовок может при необходимости содержать номер команды что позволит системе отлавливать моменты неправильной передачи в случае помех;
Второй тип подходит для передачи больших пакетов данных.
